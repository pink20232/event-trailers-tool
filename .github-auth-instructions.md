# GitHub Authentication Setup for Mobile Design System

## Option 1: Personal Access Token (Recommended for npm installs)

### Step 1: Create a Personal Access Token
1. Go to GitHub: https://github.com/settings/tokens
2. Click "Generate new token" → "Generate new token (classic)"
3. Give it a name like "Mobile Design System Access"
4. Select scopes:
   - ✅ `repo` (Full control of private repositories)
5. Click "Generate token"
6. **Copy the token immediately** (you won't see it again!)

### Step 2: Install the package using the token
Run this command (replace YOUR_TOKEN with your actual token):

```bash
npm install git+https://YOUR_TOKEN@github.com/eventbrite/mobile-design-system-atoms.git
```

Or set it as an environment variable:
```bash
export GITHUB_TOKEN=YOUR_TOKEN
npm install git+https://${GITHUB_TOKEN}@github.com/eventbrite/mobile-design-system-atoms.git
```

### Step 3: Store token securely (optional)
You can store it in your shell config to avoid entering it each time:
```bash
echo 'export GITHUB_TOKEN=YOUR_TOKEN' >> ~/.zshrc
source ~/.zshrc
```

## Option 2: SSH Keys (More secure, permanent solution)

### Step 1: Generate SSH key
```bash
ssh-keygen -t ed25519 -C "your_email@example.com" -f ~/.ssh/id_ed25519_github
```

### Step 2: Add to SSH agent
```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519_github
```

### Step 3: Add public key to GitHub
1. Copy your public key:
   ```bash
   cat ~/.ssh/id_ed25519_github.pub
   ```
2. Go to: https://github.com/settings/keys
3. Click "New SSH key"
4. Paste the key and save

### Step 4: Configure git to use SSH
```bash
git config --global url."git@github.com:".insteadOf "https://github.com/"
```

### Step 5: Install the package
```bash
npm install git+ssh://git@github.com/eventbrite/mobile-design-system-atoms.git
```
